# 🎬 CineBook

**CineBook** is a sleek, responsive movie discovery and online ticket booking web application designed to provide a seamless cinema booking experience—from browsing trending releases to selecting seats and generating booking confirmations.

## ✨ Features
- **Movie Catalog & Details:** Browse currently showing and upcoming movies with posters, ratings, genres, synopses, and trailers.
- **Showtime & Theater Selection:** Filter screenings by date, preferred theater, and show timings.
- **Interactive Seat Map:** Real-time seat selection grid displaying available, selected, and occupied seats with automatic price calculation.
- **Booking Summary & E-Ticket:** Instant checkout preview with ticket breakdown and digital booking confirmation.
- **Responsive UI:** Optimized for smooth navigation across desktop, tablet, and mobile devices.

## 🛠️ Technologies Used
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Styling:** Responsive Flexbox/Grid layouts and modern dark-cinema UI theme
- **State & Storage:** Dynamic DOM rendering and browser LocalStorage (or backend API integration if applicable)
